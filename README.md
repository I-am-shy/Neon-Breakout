# Neon Breakout 🧩

> v0.1.0 · 变更记录见 [CHANGELOG.md](./CHANGELOG.md)

霓虹风格的打砖块游戏，纯浏览器运行，**不含任何图片或音频素材**——砖块、球、道具与光效全部由代码程序绘制，音效由 Web Audio 实时合成，因此没有资源加载负担，开箱即玩。

支持桌面键鼠与移动端触屏。砖阵每局随机生成（8 款图案 × 随机镜像 × 随机缺口），既能玩 60 砖的小局，也能玩上千砖的大阵；道具与特殊砖让每局节奏都不一样。

## 功能

- **随机砖阵**：8 款图案随机抽取（菱形 / 波浪 / 拱门 / 棋盘 / 双塔 / 蜂窝 / 十字镂空 / 斜纹带），再叠加水平或垂直镜像与随机缺口——同一款图案每局落点也不同
- **可调规模**：列 10–50 × 行 4–24，最多约 1000 格（图案过滤后实际约 200–850 砖）
- **五种道具**：加宽挡板 / 多球 / 减速 / 加命 / 底部护盾；同类效果刷新时长，异类可同时生效
- **特殊砖**：光晕砖（2 击破，光晕颜色预告掉落哪种道具）、渐变砖（1 击破，掉落随机道具）
- **限时模式**：可开启 30–300 秒局时限，最后 10 秒倒计时闪烁，超时按 TIME UP 结算
- **最高分记录**：本地保存、跨会话保留，破纪录显示 ★ NEW BEST
- **难度预设**：CASUAL / STANDARD / HARDCORE 一键切换整套参数
- **移动端适配**：按视口宽度自动切换布局与操作提示，触屏拖动挡板、点按启动与暂停

## 操作

| 操作 | 桌面端 | 移动端 |
|---|---|---|
| 移动挡板 | `A` / `D` 或 `←` / `→` | 滑动屏幕 |
| 发射球 | `Space` | 点按屏幕 |
| 暂停 / 继续 | `Esc`（`P` 亦可） | 点按屏幕 |
| 重新开始 | `R` | 点按屏幕（终局后） |
| 返回开屏 | `BACK TO TITLE` 按钮 | `BACK TO TITLE` 按钮 |

- `Space` 是「启动族」：开屏开始 / 发射 / 暂停后继续 / 终局重开；游戏进行中按 `Space` 不会误触暂停
- 待发射阶段也能移动挡板，用来瞄准出球方向
- 移动端以点按为唯一入口，因此界面不设暂停按钮
- 开屏界面附有道具图例与特殊砖图例，各局配置摘要与最高分一屏可见

## 设置项

| 项 | 范围 | 默认 | 生效时机 |
|---|---|---|---|
| LIVES 生命 | 1–5 | 3 | 下一局 |
| COLUMNS 砖阵列数 | 10–50 | 50 | 下一局 |
| ROWS 砖阵行数 | 4–24 | 20 | 下一局 |
| GIFT BRICKS 光晕砖数 | 0–10 | 4 | 下一局 |
| FLOW BRICKS 渐变砖数 | 0–10 | 4 | 下一局 |
| TIME LIMIT 局时限 | 关 / 30–300 秒 | 关 | 下一局 |
| EFFECT TIME 道具时长 | 5–20 秒 | 10 | 即时 |
| BALL SPEED 球速倍率 | 0.8–1.2× | 1.0 | 即时 |
| DROP RATE 道具占比 | 0–30% | 15% | 即时 |
| DROP MODE 掉落模式 | FIXED 固定 / RANDOM 随机 | FIXED | 即时 |

预设：CASUAL（30×12、较高掉率）、STANDARD（千砖默认）、HARDCORE（50×20、1.2× 球速、随机掉落）。除预设外全部参数可单独调整，设置保存在本地，下次打开仍然生效。

## 快速开始

需要 Node.js 18+ 与 pnpm。

```bash
pnpm install
pnpm dev        # 本地预览 → http://localhost:5183
pnpm build      # 生产构建 → dist/
pnpm preview    # 预览构建产物
```

无需任何环境变量。唯一外部依赖是 Google Fonts（Chakra Petch / Share Tech Mono），离线时自动回退系统字体。

## 技术栈

| 层 | 选型 |
|---|---|
| 渲染 | Pixi v8（WebGL） |
| 物理 | Matter.js |
| 界面 | React + TypeScript + Vite |
| 样式 | Tailwind CSS |
| 状态 | zustand |
| 特效 | GSAP |
| 音效 | Web Audio API（实时合成，无音频文件） |

## 浏览器支持

需要支持 WebGL 与 Pointer Events 的现代浏览器（Chrome / Edge / Safari / Firefox 近年版本）。移动端按视口宽度自动切换布局，已在 375×667、320×568 等窄屏以及横竖屏切换场景下适配；屏幕高度不足时设置面板可滚动，确认按钮始终可见。

## 说明

- 单局玩法：无关卡推进、无在线排行榜
- 暂无背景音乐（现有音效均为实时合成）
- 道具平衡使用固定权重，未做数据采集调优
- Laser / Sticky / Fireball 等更多道具列入后续规划
